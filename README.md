# Meet & Eat Map

I want to create an app called meet2eat and this app will take into considersation all the participants geolocation and find a middle point. Then from the middle point show on all the map what are the possible food to eat or places to hangout. once voted and confirmed by everyone, everyone will be notified. I want it to be simple, jus need user name and email then ask user to share their location or manual input. Do this using onemap api
